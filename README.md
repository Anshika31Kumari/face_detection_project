# 👤 Face Detection using OpenCV

## 📌 Project Overview

Face Detection is a Computer Vision project that detects human faces in real-time using a webcam.

This project uses OpenCV's Haar Cascade Classifier to identify faces from live video input and highlights detected faces using bounding boxes.

---

## 🚀 Features

- Real-time face detection using webcam
- Uses OpenCV Haar Cascade Classifier
- Detects multiple faces in a frame
- Draws bounding boxes around detected faces
- Fast and efficient computer vision implementation

---

## 🛠️ Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier
- Computer Vision

---

## 🧠 How It Works

1. The webcam captures live video frames.
2. Each frame is converted from BGR format to grayscale.
3. Haar Cascade Classifier analyzes the grayscale image.
4. The algorithm detects face regions in the frame.
5. Bounding boxes are drawn around detected faces.
6. The processed video is displayed in real-time.

## ⚙️ Installation and Setup

 1. Clone the repository

   git clone https://github.com/Anshika31Kumari/face_detection_project.git

2. Navigate to the project directory

   cd face_detection_project

3. Install required libraries

   pip install -r requirements.txt

---

▶️ Run the Project

Run the Python file:

python face_detection.py

The webcam will open and start detecting faces in real-time.

Press 'a' key to close the application.
